# 결정 사항

슬라이드에 명시되지 않아 팀이 정해야 하는 항목이다. **권장안**은 제안일 뿐이며, 팀 결정 칸을 채운 뒤 구현한다.
결정을 바꾸면 이 표를 먼저 고치고 PR에 적는다.

| # | 항목 | 슬라이드에서 빠진 점 | 권장안 | 팀 결정 |
|---|---|---|---|---|
| 1 | systemPrompt 위치 | 필드로만 둘지, buffer 0번 system 메시지로 넣을지 | 필드로 보관, buildPrompt 맨 앞에 붙임 |  |
| 2 | 현재 입력 중복 | reply가 history에 입력을 먼저 넣고 buildPrompt(userInput)에도 넘김 | history 쪽만 포함, buildPrompt에서 다시 붙이지 않음 |  |
| 3 | keepLastK 단위 | 메시지 수인지 턴(질문+답) 수인지 | 메시지 수 |  |
| 4 | lastK > size | 처리 규칙 없음 | min(lastK, size), lastK ≤ 0이면 빈 문자열 |  |
| 5 | 버퍼 초기 용량 | 값 없음 (0이면 2배 확장해도 0) | 1 이상, 기본 4 |  |
| 6 | 생성자 마지막 숫자 | FaqBot(…,8,8), TutorBot(…,8,4) 의미 미표기 | kb / examples 초기 용량, 꽉 차면 2배 확장 |  |
| 7 | FaqEntry 필드 | 정의 없음, addFaq 인자 2개 | keyword, answer |  |
| 8 | 키워드 매칭 | 여러 개 매칭, 대소문자 처리 불명 | contains, 매칭된 항목 전부 첨부 |  |
| 9 | 스텁 응답 규칙 | "프롬프트 길이 기반" 예시뿐 | 같은 입력이면 같은 출력, 여러 줄, Random 금지 |  |
| 10 | temperature / maxTokens | 스텁에서 쓰는 방법 없음 | maxTokens만 응답 글자 수 상한, temperature는 저장만 |  |
| 11 | 기본 postProcess | 부모 동작 미정 | trim() |  |
| 12 | KoreanBot 검증 | 스텁은 실제 한국어 생성 불가 | 생성된 프롬프트를 출력해 지시문 포함 확인 |  |
