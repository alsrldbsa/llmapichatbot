## 작업 규칙

- 브랜치 이름: `이슈번호-짧은설명` (예: `3-conversation-buffer`)
- 커밋은 자기 담당 파일만. 다른 사람 파일을 고쳐야 하면 이슈에 먼저 댓글.
- PR 본문에 `Closes #이슈번호`, 리뷰 1명 이상 승인 후 병합.
